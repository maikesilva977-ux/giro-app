# GIRO

Aplicativo de gestão de revendas — controle de produtos, compras, estoque, vendas, lucro e desempenho.

> "Comprar → vender → recuperar o dinheiro → reinvestir → crescer."

## Status do projeto

🚧 Em desenvolvimento — Etapa 1 (estrutura inicial, dashboard e produtos)

## Tecnologias

- HTML, CSS e JavaScript puro (ES Modules)
- Firebase (a partir da Etapa 2)
- PWA (a partir da Etapa 6)

## Como rodar localmente

Este projeto não precisa de instalação nem build. Basta abrir o `index.html` em um navegador, ou acessar a versão publicada:

👉 https://maikesilva977-ux.github.io/giro-app/
